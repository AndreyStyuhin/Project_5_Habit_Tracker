# Project 5: Habit Tracker: Backend 🚀

## Описание

**Habit Tracker** — это мощное **backend-приложение** для отслеживания и управления привычками, построенное на **Django** и **Django REST Framework**. Приложение реализует полноценный **REST API**, который обеспечивает создание, управление и валидацию привычек, а также отправку **асинхронных напоминаний** через **Telegram-бот** с помощью **Celery** и **Redis**.

Проект разработан с учетом требований к современным API: использует **JWT-аутентификацию**, имеет полную **документацию (Swagger/ReDoc)** и покрыт **юнит-тестами** (pytest).

| **Ключевые особенности** | **Валидация привычек** |
| :--- | :--- |
| 🛡️ JWT-аутентификация | ⏱️ Длительность выполнения: **$\le 120$ секунд** |
| 🔔 Telegram-напоминания (Celery) | 🗓️ Периодичность: **$\ge 1$ раза в 7 дней** |
| 📄 Документация API (Swagger/ReDoc) | 🤝 Исключение конфликта вознаграждения и связанной привычки |
| 🔎 Публичный доступ к привычкам | 🚫 Ограничения для "приятных" привычек (нет вознаграждения/связанной) |

## Функционал приложения

### Управление пользователями и аутентификация

  - **Регистрация**: Использование **email** в качестве логина.
  - **Уведомления**: Поддержка **Telegram ID** для отправки напоминаний.
  - **Авторизация**: Реализована на базе **JWT-токенов** (**djangorestframework-simplejwt**).

### Работа с привычками (CRUD)

  - **Создание и Валидация**: Добавление привычек с обязательными полями (место, время, действие) и валидацией правил.
  - **Управление**: Полный CRUD-функционал (только для собственных привычек).
  - **Просмотр**: Доступен просмотр **публичных привычек** всех пользователей, а также списка своих привычек.
  - **Статистика**: Просмотр списков с **пагинацией** (по 5 элементов на страницу).

### ⏰ Асинхронные напоминания и валидация

  - **Напоминания в Telegram**: Автоматическая отправка уведомлений о **полезных привычках** по расписанию через **Celery** и **Redis**.
  - **Celery Beat**: Запуск задачи проверки привычек **каждую минуту**.
  - **Строгая Валидация**: Обеспечение соблюдения всех бизнес-правил при создании и обновлении привычек (см. таблицу выше).

## Установка и запуск ⚙️

### 1\. Подготовка

1.  **Клонирование репозитория:**
    ```bash
    git clone https://github.com/AndreyStyuhin/Project_5_Habit_Tracker.git
    cd Project_5_Habit_Tracker
    ```
2.  **Создание и активация виртуального окружения:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # Unix/Mac
    venv\Scripts\activate     # Windows
    ```
3.  **Установка зависимостей:**
    ```bash
    pip install -r requirements.txt
    ```

### 2\. Конфигурация

4.  **Настройка переменных окружения:**

    ```bash
    cp .env.example .env
    ```

    Отредактируйте файл `.env`, указав:

      - **`SECRET_KEY`** (сгенерируйте новый).
      - **`TELEGRAM_BOT_TOKEN`** (токен вашего бота).
      - Убедитесь, что **Redis** запущен (по умолчанию `localhost:6379`).

5.  **Применение миграций и создание суперпользователя:**

    ```bash
    python manage.py migrate
    python manage.py createsuperuser
    ```

### 3\. Запуск

6.  **Запуск сервера разработки:**
    ```bash
    python manage.py runserver
    ```
7.  **Запуск Celery Worker и Beat (обязательно в двух ОТДЕЛЬНЫХ терминалах):**
    ```bash
    # Терминал 1: Celery Worker
    celery -A habit_tracker worker -l info

    # Терминал 2: Celery Beat (Планировщик)
    celery -A habit_tracker beat -l info --scheduler django_celery_beat.schedulers:DatabaseScheduler
    ```
    💡 **Примечание**: Убедитесь, что **Redis** запущен и доступен.

## Использование API и Документация 📖

### Основные Endpoints

Для всех защищенных эндпоинтов используйте заголовок: `Authorization: Bearer <access_token>`.

| Категория | Метод | Endpoint | Описание |
| :--- | :--- | :--- | :--- |
| **Аутентификация** | `POST` | `/api/v1/token/` | Получение JWT-токенов (логин). |
| | `POST` | `/api/v1/users/register/` | Регистрация нового пользователя. |
| **Привычки** | `GET, POST` | `/api/v1/habits/` | Список своих привычек / Создание новой. |
| | `GET, PUT, PATCH, DELETE` | `/api/v1/habits/<id>/` | Детальные операции над привычкой. |
| **Публичные** | `GET` | `/api/v1/habits/public/` | Список общедоступных привычек (пагинация). |

### Документация

Вы можете взаимодействовать с API и просматривать все эндпоинты через интерактивную документацию:

  - **Swagger UI**: [http://127.0.0.1:8000/swagger/](http://127.0.0.1:8000/swagger/)
  - **ReDoc**: [http://127.0.0.1:8000/redoc/](http://127.0.0.1:8000/redoc/)

## Интеграция с Telegram 💬

Проект использует Telegram Bot API для отправки **персонализированных напоминаний** о **полезных привычках**.

### Механизм работы

1.  **Конфигурация**: Укажите `telegram_id` при регистрации или в профиле.
2.  **Celery Beat**: Запускает задачу `send_habit_reminders` каждую минуту.
3.  **Проверка**: Задача проверяет все полезные привычки, время которых совпадает с текущим, и с момента последнего напоминания прошло достаточно времени, согласно периодичности.
4.  **Отправка**: Сообщение отправляется с помощью простого `requests`-запроса к Telegram Bot API (логика в `apps/habits/services.py`).

### Пример уведомления

Пользователь получит сообщение в Telegram, содержащее ключевую информацию о привычке:

```
🔔 *Напоминание о привычке!*

Пора выполнить: *{action}*
Где: *{place}*
Время на выполнение: *{duration} сек.*

🏆 Вознаграждение: *{reward}* (или связанная привычка)
```
